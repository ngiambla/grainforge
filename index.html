How GrainForge works

  1. Start from photos, an example, or a file

    • Click From photos, add a few pictures of the piece (front, side and top work best), click the piece in each to outline it, and enter one real measurement. You can also open an example or a .grainforge file.

  2. Check the model

    • Rotate the 3D view to compare it with your photos. Fix any dimension in the sidebar; every part follows.

  3. Tell it about your workshop

    • Pick your skill level, and switch on Only use tools I have to choose your tools. The cut list then changes to suit: which saw makes each cut, boards bought at width if you can't rip, stock bought at thickness if you can't plane, ready-glued panels if you have no clamps. Joints change to ones you can make, and anything you're missing is listed.
    • Save tools file keeps your skill and tools in a .gftools file you can load into any project or send to a friend. They're also remembered in this browser for new projects.

  4. Review the plan

    • The tabs show the cut list, what to buy, how to lay out the cuts, each joint (you can change any of them), the tools and the build steps.

  5. Export and save

    • Export PDF gives you a printable plan. Save downloads a .grainforge file you can reopen or share.

Everything runs in your browser. Photos are never uploaded; the outline model downloads once (about 40 MB) and is cached. Always check measurements before you cut.
